# Task8 bayan
## Утилита для анализа дубликатов файлов
Доступные параметры командной строки:
- -h [ --help ]                отобразить справку;
- -d [ --scan_dir ]            перечень сканируемых директорий;
- -i [ --ignor_dir ]           перечень игнорируемых директорий;
- -m [ --mask ] arg (=*)       перечень масок файлов для анализа [ex.: *.log, *.txt, * - любые файлы];
- -s [ --file_size ] arg (=1)  минимальный размер анализируемого файла, в байтах;
- -l [ --level ] arg (=0)      уровень сканирования [ex.: 0 - только директории, указанные в --scan_dir];
- -S [ --block_size ] arg (=5) размер блока данных для разового чтения с диска, в байтах;
- -H [ --hash ] arg (=md5)     используемый алгоритм хэширования [ex.: md5, sha-1].
